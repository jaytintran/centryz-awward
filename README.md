# ⚡️ Centryz – Zentry-Inspired Web Experience

Centryz is a bold, immersive clone of the Zentry website — crafted to showcase scroll-triggered animations, geometric transitions, and cinematic video storytelling. Designed to capture that high-end, **Awwwards-worthy** aesthetic, Centryz delivers a smooth, modern UI/UX experience that's both visually stunning and highly interactive.

> Learn how to engineer luxury in motion — the kind of experience that captivates users and screams world-class design.

---

## 🔧 Tech Stack

- **React.js**: For building the dynamic, interactive interface.
- **Tailwind CSS**: For rapid, responsive styling.
- **GSAP (GreenSock Animation Platform)**: For advanced, high-performance animations.
- **Vite.js**: For fast, efficient development.
- **Three.js**: For 3D hover effects and interactive elements.

---

## ✨ Key Features

- **🎯 Scroll-Based Animations**  
  Scroll-triggered motion effects that bring content to life with fluidity and impact.

- **🧩 Geometric Clip-Path Transitions**  
  Advanced CSS `clip-path` animations create seamless, eye-catching section reveals.

- **🌐 3D Hover Effects**  
  Modern, interactive hover states that add depth and responsiveness.

- **🎥 Cinematic Video Transitions**  
  Embedded video storytelling elements for immersive flow and engagement.

- **🧠 Smooth UI/UX**  
  A polished, luxurious interface built for intuitive navigation and fluid transitions.

- **📱 Fully Responsive Design**  
  Pixel-perfect on all devices, from mobile to desktop.

> Built with clean code architecture, modular components, and high reusability in mind.

## 🚀 Quick Start

Get up and running in minutes:

### 🔍 Prerequisites

Ensure you have these installed:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)
- npm (comes with Node.js)

### 📦 Clone the Repo

```bash
git clone https://github.com/jaytintran/centryz-awward.git
cd centryz-awward
```

### 📥 Install Dependencies

```bash
npm install
```

### 🔄 Run the Dev Server

```bash
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) to see it in action.
